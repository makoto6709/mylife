# MyLife 家計簿 PWA（試作版）

## 概要
Windowsだけで管理できる、iPhoneのホーム画面から起動可能な家計簿です。HTML/CSS/JavaScript製。Apple Developer Programは不要です。GitHub Pagesの無料枠とGoogle Sheets APIの通常の無料利用枠を想定しています。**公開済みURLは同梱されていません。**

## 導入
1. GitHubで新しい公開リポジトリを作り、`kakeibo_pwa`フォルダの**中身**（index.htmlなど）をルートにアップロードします。GitHub Pagesの設定で `Deploy from a branch` → `main` → `/ (root)` を選び、HTTPSの公開URLを確認します。GitHub Pagesは静的サイトの公開です。リポジトリが公開の場合、コードは他人に閲覧可能です。家計簿の記録データはリポジトリには入れないでください。
2. Googleスプレッドシートを新規作成して、URLの `/d/` と `/edit` の間のIDを控えます。シート名は自動で `取引履歴` が作成されます。
3. Google Cloud Consoleでプロジェクトを作り、**Google Sheets API** を有効にします。OAuth同意画面を設定し、OAuthクライアントの種類を **ウェブアプリケーション** にして、**承認済みのJavaScript生成元** にGitHub Pagesのオリジン（例 `https://ユーザー名.github.io`、末尾パスなし）を追加します。クライアントシークレットはアプリに入れません。OAuthの公開範囲・テストユーザー設定を確認してください。テストモードは利用可能ユーザーや認可に制限があります。
4. iPhoneのSafariで公開URLを開き、アプリの設定タブにOAuthクライアントIDとスプレッドシートIDを入力し、Googleに接続します。Googleからの権限要求を確認して許可し、`同期する`を押します。
5. Safariの共有メニューから `ホーム画面に追加` を選びます。iOSのバージョンによってメニュー表記が異なることがあります。

## 使い方
- 音声入力：ブラウザがSpeechRecognitionに対応している場合、音声から金額・日付・分類候補を作成します。非対応の場合は手入力画面のメモ欄を選択し、iPhoneキーボードの音声入力を使ってください。音声入力のブラウザサポートやネット接続の要否は環境によります。
- 画像：Tesseract.jsをCDNから読み込み、端末のブラウザで日本語・英語OCRを実行します。初回はネット接続が必要で、読み取りには時間がかかります。OCRの金額・日付・店名は**必ず確認**してください。レシート画像自体はGoogle Sheetsにアップロードしません。
- 支出区分：通常支出、収入、還元収入、株主優待、対象外、秘密支出。通常と秘密支出は月間支出に合算。対象外と優待は現金収支に加算しません。
- 同期：Googleログイン後、画面の「同期する」を押すと取引履歴シートへ双方向同期します。オフライン記録は端末内に保管。更新時刻の新しい取引を優先します。複数端末から**同時に**同期する運用は想定していません。
- CSV：バックアップのエクスポートと再取り込みに対応。

## 重要な制限
- **試作版です。実際の家計データを大量投入する前に、テスト用シートで同期と復元を確認してください。** 実機Safari/Google認証/OCRの統合動作は未検証です。
- PWAはiOSの**ネイティブウィジェット（WidgetKit）**を作れません。ホーム画面アイコンからの起動になります。
- Google認証はGoogle Identity Servicesの短期アクセストークンを使います。期限切れ後は再認証が必要です。Googleの同意画面設定によっては認可が制限されます。
- ローカルデータはブラウザのlocalStorageです。Safariのサイトデータ削除やストレージ制限で失われる可能性があるため、同期かCSV保存を定期的に行ってください。
- Google Sheets APIへのアクセスは**ログインした本人のOAuthトークン**を利用し、秘密の共通APIキーや公開Apps Scriptエンドポイントを使用しません。
- OCR用ライブラリをCDNからロードします。オフラインでは画像認識が動作しない場合があります。
- アプリのコードは公開できますが、スプレッドシートIDをGitHubへコミットしないでください。OAuthクライアントIDは公開可能な識別子です。
- 初期版ではGoogle Sheets同期は取引履歴のみ。カテゴリ設定や月次集計はアプリ内で計算します。


## MyLife統合・お得管理（v2）
- お得額・お得種別を取引に追加。ポイント還元、株主優待、クーポン割引、キャンペーン特典、その他を記録できます。
- 月次のお得額、お得率（お得額÷（現金支出＋お得額））、お得内訳を表示します。
- 取引履歴シートは A:K の11列です。既存の9列データは空欄を0として読み込めます。
- 還元収入は従来どおり収入に計上されます。お得額にも入力すると両方の指標に表示されますが、収支計算に二重加算されません。ポイントの獲得・利用を重複してお得計上しないでください。
- MyLife統合時には家計簿を独立モジュールとして扱い、共有カレンダー側へ家計簿データを渡さない設計です。現状はアクセス権限を分離した統合済み製品ではありません。
- Google同期は実機検証前です。同期前にCSVバックアップを推奨します。
