# MyLife 家計簿 v4.1.0

公開先: https://makoto6709.github.io/mylife/kakeibo_pwa/

このフォルダだけを更新します。既存のリポジトリや他のMyLifeモジュールを初期化する必要はありません。既存の端末データの保存キーと取引履歴の11列形式を維持しています。

## iPhoneで音声入力

1. 「音声で記録」を押します。
2. 入力欄をタップし、iPhone標準キーボードのマイクを押します。
3. 「スーパーで500円」などと話し、「内容を確認する」を押します。
4. 内容を確認し「保存する」を押します。

WebページからiPhone標準キーボードのマイクを自動起動することはできません。キーボードのマイクは本人が押してください。マイクがない場合は「設定 → 一般 → キーボード → 音声入力を有効にする」を確認します。標準音声入力が使えない場合も同じ欄に文字を入力できます。

| 入力 | 初期設定 |
| --- | --- |
| 500円 | 今日・支出500円・未分類 |
| コンビニで500円 | 今日・支出500円・食費 |
| 昨日スーパーで2500円 | 昨日・支出2,500円・食費 |
| 母の買い物で3000円 | 対象外3,000円 |
| ポイント100円もらった | 還元収入100円・お得100円 |
| 株主優待で1000円得した | 現金取引0円・お得1,000円 |
| ポイント100円使った | 対象外・お得額0円（獲得時との二重計上防止） |
| クーポン200円得した | 現金取引0円・お得200円 |

全角数字・五百円・二千五百円・1万円にも対応。金額不明や複数金額の場合は確認画面に案内します。複数金額を含む文章は最初の金額を候補として表示するため、支払いと割引を必ず確認してください。現金とポイントを併用した場合は現金支払いだけ別途登録してください。文章を解釈する有料AI APIは使用しません。

## 集計・お得

表示月を選ぶと月次集計が切り替わります。通常支出・秘密支出を分け、選択年の通常支出・収入・お得額も自動計算します。月末の操作は不要で、アプリを開いた時点の保存データから計算します。アプリを閉じたままのバックグラウンド帳票作成・通知はありません。

対象外は支出・収入・お得集計から除外。ポイント獲得は還元収入とお得の両指標に表示しますが、通常支出から差し引く処理はしません。お得率は「お得額 ÷（通常支出＋お得額）」です。秘密支出をこの分母へ混ぜません。

## 秘密支出

秘密支出はこの端末にだけ保存し、Google Sheetsへの送信対象から除外します。同期先に旧バージョンの秘密支出が残っている場合は、書き込みを止めて案内を表示します。自動削除はしません。通常支出から秘密支出へ変更した際にも、同期先に同じIDが残る場合は停止します。非共有の別ファイルへの退避・同期先からの削除が必要です。

この版は個人用です。同じ端末の利用者に対するロック機能はありません。CSVには秘密支出を含む全記録が入ります。将来のMyLife共有機能へ家計簿データやCSVを渡さないでください。共有版でのユーザー認証・サーバー側アクセス権分離は未実装です。秘密支出の複数端末同期もこの版の対象外です。

## Googleスプレッドシート連携

現状はGoogle Identity ServicesとGoogle Sheets APIによる本人認証です。APIキーやクライアントシークレットをコードに保存しません。アクセストークンはメモリにのみ保持します。

1. 自分用の非共有スプレッドシートを用意します。
2. Google CloudでGoogle Sheets APIを有効化し、ウェブアプリ用OAuthクライアントIDを作成します。
3. 承認済みJavaScript生成元に `https://makoto6709.github.io` を設定します。OAuth同意画面・テストユーザーも設定します。
4. アプリの設定にクライアントIDとシートID（URLも可）を入力し、保存します。
5. 「Googleに接続」で本人が認証し、「同期する」を押します。

作成・同期するのは `取引履歴` シートのみです。月次集計・カテゴリ設定・分類ルール・設定の4シートへの書き出しや設定読み込みは未実装です。集計はアプリ内、カテゴリと分類ルールはコード内、連携設定は端末内に保存します。OAuthの権限要求を本人が確認してください。

取引履歴の列: `id,date,type,category,amount,memo,payment,updatedAt,deleted,benefitType,benefitAmount`。旧9列にも対応します。固有IDでマージし、編集・削除時も同じIDを使います。削除は同期用の削除フラグを残します。

同期失敗時は端末の未同期データを保持します。認証が有効な間は保存・通信回復・画面復帰時に再同期します。トークンの期限切れやアプリ再起動後には本人による再認証が必要です。認証ポップアップを通信回復時に勝手に開きません。同期中に行った編集も未同期で保持します。

Google Sheetsはファイル全体の権限で管理してください。シートタブの非表示や保護は秘密データのアクセス分離になりません。同期は読み取り後に書き戻す方式のため、複数端末からの同時同期には対応していません。

## 画像・CSV・オフライン

- 画像OCRは既存のTesseract.js方式を維持しています。画像ファイルはSheetsにアップロードしません。CDNや言語データの取得には通信が必要です。OCRの金額・店名・日付は確認してください。
- CSVで全記録のバックアップ・復元ができます。既存9列と11列を受け付けます。
- 音声の文字列解析と手入力は端末内で動作します。iPhoneの音声入力自体の利用条件は端末側に依存します。
- Safariのサイトデータを削除しないでください。更新で直らない場合も先にCSVを保存してください。

## 写真・電子レシート取り込み（v4.1.0）

「写真・ファイル」からカメラ撮影・写真ライブラリ・ファイル選択を使えます。写真、PDF（文字入り／スキャン）、TXT、1件分のCSV/TSV、単一オブジェクトJSON、HTMLを読み込みます。メールやExcelはPDFに保存して選択してください。1回にレシート1件、最大20MB、文字ファイルは2MB、PDFは5ページまで。複数取引のCSV一括登録は対象外です。既存のバックアップCSV復元は設定に残しています。

読み取り後の文字・金額候補を画面に表示し、「取引へ反映」で金額・日付・店名の確認画面に進みます。最後に「保存する」で取引を記録します。ファイルを選んだだけでは登録しません。元画像・PDF等を保管する機能ではありません。取引データのみ端末に保存し、通常の記録は既存のSheets同期の対象となります。ファイル自体を外部へ送信しません。

画像は長辺2000px／最大300万画素へ調整し、日本語OCRのみを起動してメモリ消費を抑えます。準備・認識の進捗、タイムアウト、中止、再読み取り、失敗時の文字貼り付けを追加しました。Tesseract.js 5.1.1・日本語データとPDF.js 4.10.38を必要時に配信元から読み込みます。初回は通信が必要です。WebAssembly非対応、メモリ不足、写真形式や通信制限などで失敗する場合は画面に案内を出します。iPhoneのHEICが開けない場合はJPEG/PNGまたはスクリーンショットを選択してください。

認識精度を保証するものではありません。小計・税・お預り・釣銭を除いて合計／支払金額を優先しますが、複数候補は確認が必要です。日付を抽出できない場合は確認画面で今日を初期値とします。

`node kakeibo_pwa/tests/receipt.cjs` で合計優先、釣銭・税の除外、日付、複数候補、数字だけの税額など12例と、撮影・写真・ファイルの選択欄を検証します。iPhone実機での撮影後の復帰・HEIC等は別途確認が必要です。
